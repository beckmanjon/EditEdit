# Question locking and acceptance criteria

Question locking is the sovereignty lock. Before strand work, state what kind of question is actually being asked.

Common types include:

- Thesis-expression
- Decision
- Risk-control
- Timing
- Position-management
- Identity/meaning
- Interpretive / Research

State a **sovereign decision sentence** when a decision is required. Then define acceptance criteria before execution in Given/When/Then form.

## Example

```text
Given: a constrained decision scope and stated evidence boundary,
When: the protocol completes,
Then: it returns a permitted action, invalidation criteria, watch items,
or an explicit escalation status.
```

If the locked question becomes wrong during the run, surface the defect and re-lock it. Do not silently drift into a different question.
