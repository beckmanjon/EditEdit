# Framework invariants

These source-aligned v1.0 invariants must remain true.

1. The mandatory closure skeleton is Plan → Apply → Unify.
2. A run locks the real question and defines acceptance criteria before substantive execution.
3. Base context remains sovereign; divergence cannot silently rewrite it.
4. Generated strand output remains candidate material until independently qualified.
5. High-temperature output that drifts from the locked question is flagged or killed.
6. Mythic/Symbolic material is labeled Symbolic Insight, Bias Warning, or Poetic Color and never independently drives a decision.
7. Poetic Color is excluded from decision logic.
8. The Kill List explicitly records discarded material and justification.
9. KDP follows Execute / Qualify and records action, invalidation, answer-changing conditions, and watch items.
10. `DONE`, `DONE_WITH_CONCERNS`, `NEEDS_CONTEXT`, and `BLOCKED` remain valid outcomes.
11. When a defect appears, diagnostic routing classifies Intent issue, Spec issue, Evidence gap, or Structural blocker before patching.
12. Audit records expose question type, selected strands/temperatures, decisions, and provenance—not hidden chain-of-thought.
