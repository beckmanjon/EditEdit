# Regression cases

| ID | Regression risk | Required protection |
| --- | --- | --- |
| R1 | Treating a coherent answer as authorized | Require an explicit Authority Gate status. |
| R2 | Treating context as proof | State that base context governs scope while reality governs truth. |
| R3 | Returning Mythic material as evidence | Quarantine it and translate it into a testable question or falsifier. |
| R4 | Omitting a closed-loop status when context is missing | Permit `NEEDS_CONTEXT` as success in procedural closure. |
| R5 | Hiding rejected alternatives | Preserve the Kill List in the receipt. |
| R6 | Replacing auditability with private reasoning | Record rationale and provenance, not hidden chain-of-thought. |
| R7 | Over-applying the protocol to routine work | Use the complexity budget to keep reversible work lightweight. |
