# Regression cases

| ID | Regression risk | Required protection |
| --- | --- | --- |
| R1 | Representing PAUL as a five-stage loop | Preserve Plan → Apply → Unify and keep Execute/Qualify inside Apply. |
| R2 | Starting strand work without locking the question | Require question type, decision sentence where relevant, and Given/When/Then criteria. |
| R3 | Letting fractal output rewrite base context | Run a base-context sovereignty check during Unify. |
| R4 | Treating high-temperature novelty as evidence | Flag or kill drifted output during qualification. |
| R5 | Letting Symbolic material drive an action | Apply labels, quarantine, and KDP qualification. |
| R6 | Omitting discarded outputs | Preserve the Kill List with justifications. |
| R7 | Replacing closure with apparent completion | Require planned-versus-actual reconciliation and a final escalation status. |
| R8 | Patching an issue without diagnosis | Route Intent, Spec, Evidence, or Structural blocker first. |
