# PAUL vs LSD

**PAULvsLSD v1.0** is a unified reasoning protocol that combines:

- **Beckman v3.1 / PAUL Application Layer:** Listen → Search → Decide → Dream; Grounded, Structural, Strategic, and Adversarial strands; Low/Medium/High passes; KDP; quarantined Mythic Wild Card.
- **LSD Fractal Reasoning:** six interpretive strands across Low, Medium, and High temperatures; amalgamation; explicit Kill List; base-context sovereignty.
- **PAUL Framework loop discipline:** Plan → Apply → Unify, with acceptance criteria, Execute/Qualify inside Apply, mandatory closure, and explicit escalation statuses.

Its purpose is disciplined operational clarity plus controlled fractal depth—without narrative contamination, context drift, or false completion.

## Modes

- **PAUL mode:** strict Beckman v3.1 operational discipline.
- **LSD mode:** full six-strand, three-temperature controlled divergence.
- **Hybrid PAUL+LSD:** the recommended serious-work mode, applying selective fractal expansion inside mandatory Plan → Apply → Unify.

## Core flow

```text
Question lock + acceptance criteria
  ↓
PLAN
  ↓
APPLY
  ├─ Listen → Search → Decide → Dream
  ├─ Low → Medium → High passes
  └─ Execute / Qualify
  ↓
UNIFY
  ├─ Kill List + base-context fidelity
  ├─ KDP / final decision gate
  └─ action, invalidation, watch items, closure
```

Base context is sovereign. Mythic illuminates but does not govern. Symbolic material is labeled and quarantined; it cannot independently establish facts, raise empirical confidence, resolve disagreement, or authorize action.
