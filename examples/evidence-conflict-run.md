# Evidence-conflict run

> Synthetic scenario

## Question

Which of two internal procedure summaries should guide a team’s next routine check?

## Plan

- **Scope:** Select an interim operational reference; do not determine policy truth.
- **Evidence boundary:** Two dated summaries and the absence of a current signed procedure.
- **Acceptance criterion:** Avoid presenting an unsupported procedure as authoritative.

## Apply

Source A says the check is weekly. Source B says it is biweekly. Both appear credible but neither establishes current approval.

## Qualify

The sources conflict. A candidate that treats either summary as settled policy is rejected. A bounded candidate is: “Use the more recent summary only as an interim reference while confirming the current authorized procedure.”

## Authority Gate

- **Status:** Qualified recommendation
- **Not authorized:** Declaring either cadence to be policy.
- **Required next step:** Ask the procedure owner to confirm the current version.

## Unify

Use the more recent summary as a clearly labeled interim reference; do not represent it as the controlling procedure.

- **Confidence:** Limited by unresolved source conflict.
- **Falsifier:** A current authorized procedure supersedes the interim reference.
- **Final status:** `DONE_WITH_CONCERNS`
