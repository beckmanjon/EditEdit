# Needs-context run

> Synthetic scenario

## Question

Should a new data source be added to a recurring report?

## Plan

- **Scope:** Evaluate fit for the report.
- **Needed context:** Report purpose, source provenance, collection method, audience, and permission to use the data.

## Apply

The request provides only the source name. It does not provide the report’s objective, the data’s provenance, or whether use is authorized.

## Qualify

No responsible fit assessment can be made. Inventing assumptions would make the response look complete while concealing the missing boundary.

## KDP / final decision gate

- **KDP result:** The unsupported “add it” candidate is placed on the Kill List.
- **Permitted output:** A request for the listed context.

## Unify

Return the context request and defer the recommendation.

- **Final status:** `NEEDS_CONTEXT`

This is successful procedural closure. The loop has produced the correct bounded output without pretending to know more than it does.
